THỰC HÀNH CÁC CÁCH NHÚNG CSS

1. Tiêu đề sử dụng Inline CSS

Đoạn văn này được định màu chữ dương trực tiếp bằng thuộc tính style (Inline CSS).

2. Tiêu đề sử dụng Internal CSS

Đoạn văn này được định màu tím bằng thẻ <style> đặt ở thẻ <head> (Internal CSS).

3. Tiêu đề sử dụng External CSS

Đoạn văn này được định màu cam thông qua file style.css riêng biệt (External CSS).
